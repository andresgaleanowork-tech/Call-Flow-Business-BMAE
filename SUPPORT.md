# Soporte

| Tipo | Canal | Respuesta |
| :-- | :-- | :-- |
| Docs del estado | [`docs/cierre.md`](docs/cierre.md) | siempre vigente (se actualiza en cada PR de estado) |
| Decisiones arquitectónicas | [`docs/github-total.md`](docs/github-total.md) + ADRs en `docs/` | siempre vigentes |
| Deploy / gestos humanos | [`docs/deploy-github.md`](docs/deploy-github.md) | checklist «push y salir» |
| Bug operativo | Issue privado etiqueta `bug` y plantilla **Incidencia** | primer triage ≤ 48 h laborables |
| Duda de uso Call-Flow | Guía de onboarding: `[?]` dentro de `#/callflow` | inmediata (en la app) |
| Duda de facturación VeriFactu | Issue con plantilla **🧾 Factura VeriFactu** (es un proceso humano: certificado + aprobación) | cuando el responsable apruebe |

No hay soporte por email externo en este proyecto: todo queda registrado en
GitHub para que la trazabilidad sea completa (principio GitHub-Total).
