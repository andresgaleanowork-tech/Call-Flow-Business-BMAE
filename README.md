# 🎧 Guion NEURO · Ventas Telefónicas PYME B&M Asesores Energeticos

Herramienta de trabajo para el comercial en llamada y para su formación.
**Todo el proyecto cabe en un solo archivo HTML** (sin servidor, sin npm, sin conexión):

- 🗺️ **Árbol de decisión en vivo** — tocas la respuesta del cliente y el guion salta al bloque exacto
- 🛡️ **15 objeciones** con protocolo Validar → Desactivar → Reencuadrar → Avanzar, más 2ª ronda
- 🇪🇸 **Naturalidad española (Castellano)**: cada bloque explica por qué suena bien y da alternativas
- 🔬 **Capa NEURO**: cada línea marca el mecanismo psicológico SI (pérdida, autoridad, escasez, Zeigarnik…)
- 🎭 **Modo roleplay** con feedback + 📈 panel de KPIs + 🎯 **modo Foco** (árbol + discurso XL)
- 🎓 **Onboarding de 12 módulos** con quiz, casos reales, checklist y progreso guardado en local

**Uso:** abrir `index.html` en Chrome/Edge, rellenar variables y llamar. Uso interno — B&M Asesores Energéticos.
