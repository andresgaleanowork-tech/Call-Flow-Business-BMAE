🛡 Publicar / rotar la clave para todo el equipo

Pega la clave real (PAT con acceso de contents:read+write a AMBOS repos: CFB-datos-equipo y Call-Flow-Business-BMAE) y elige la contraseña del equipo — una frase corta y fácil de decir en voz alta (ej. «faro-mantel-luna-29», mín. 12 caracteres). Se cifra aquí mismo (AES-GCM-256 + PBKDF2 ×250.000) y solo viaja cifrada.

📨 Enlace de acceso (1 clic para el comercial)
Mánda este enlace por WhatsApp/correo interno: quien lo abra entra directo y solo pone su ID — la contraseña viaja DENTRO del enlace (en el «#», que nunca toca el servidor) y se borra sola de la barra de direcciones tras usarla. Caduca si cambias la contraseña del equipo.
